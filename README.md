# Insights do Cosmos

Site oficial do projeto **Insights do Cosmos** — plataforma de espiritualidade, autoconhecimento e tarô.

## 🌟 Funcionalidades

- Calculadora de Arcano Pessoal (numerologia arquetípica)
- Captura de e-mails para envio da leitura personalizada
- Design místico com identidade visual própria

## 🚀 Deploy

Este site está hospedado via **GitHub Pages**.

Domínio: `insightsdocosmos.com`

## 📁 Estrutura

```
/
├── index.html      ← Página principal
├── logo.png        ← Logo sem fundo (marca d'água)
├── logo-bg.png     ← Logo com fundo roxo (perfil)
└── CNAME           ← Configuração de domínio personalizado
```

## ⚙️ Integração de E-mail

A função `enviarEmail()` em `index.html` está preparada para integração com:
- **Mailchimp** (recomendado para iniciantes)
- **ConvertKit** (mais robusto para funis)
- **Brevo** (gratuito até 300 emails/dia)
